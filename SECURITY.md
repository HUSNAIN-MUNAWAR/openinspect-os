# Security Policy

Do not open public issues for exploitable vulnerabilities involving authentication, tenant isolation, report integrity, model replacement, object access or edge synchronization. Use GitHub private vulnerability reporting for the repository owner.

Supported security fixes target the latest release. Include reproduction steps, affected version, impact and a safe proof of concept. Never attach real critical-infrastructure media, credentials or customer data.

The full threat model is in [`docs/SECURITY.md`](docs/SECURITY.md).
