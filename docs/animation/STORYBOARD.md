# Production Inspection Reel Storyboard

The reel is a short looping reference animation. Each frame is generated from the same deterministic synthetic sequence so reviewers can reproduce it exactly.

| Scene | Frames | Visual | Message |
|---|---:|---|---|
| Capture | 1–3 | Raw underwater pipeline scene with timestamp | Evidence begins as a sensor frame |
| Enhance | 4–6 | Contrast-balanced scene and quality signal | The pipeline makes visibility explicit |
| Segment | 7–9 | Candidate region highlighted in cyan | The model produces inspectable evidence |
| Review | 10–12 | Confidence, visibility, and provenance strip | A reviewer receives a bounded decision aid |

## Visual rules

- Keep synthetic-data provenance visible in the footer.
- Show model name and version on every frame.
- Show confidence and visibility as evidence fields, not as a claim of certainty.
- Avoid photorealistic labels that imply real assets or customer data.
- Keep the reel readable at 960×540 for README, portfolio, and presentation use.
