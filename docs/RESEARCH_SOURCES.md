## Implementation boundary created by the research

- The bundled crack and pipeline algorithms are **CPU reference baselines**, not certified inspection instruments.
- Severity is configurable decision-support metadata and always requires qualified human approval.
- The platform does not claim general corrosion detection because the default dataset has no real corrosion labels.
- Full SLAM is not claimed; the implemented path is timestamped navigation, trajectory reconstruction and coverage analysis.
- External datasets remain opt-in even when openly licensed, so their attribution, checksums and split manifests stay explicit.
- The architecture supports PostGIS, MinIO, Redis and MLflow integration, while the deterministic demo remains runnable on a modest CPU with SQLite/local object storage.
