# OpenInspect OS Project-Owned Demo Dataset

**Version:** 0.1.0  
**License:** Creative Commons Attribution 4.0  
**Purpose:** Reproducible software and algorithm validation without redistributing third-party inspection data.

## Capture and generation

The dataset is procedurally generated by `scripts/generate_demo_data.py`. Structural samples simulate concrete texture, branching dark cracks, blur, occlusion and surface damage. Pipeline samples simulate underwater colour attenuation, turbidity, a metallic linear pipe, partial occlusion and low-visibility frames. Sonar and navigation records are generated from documented mathematical functions with timestamped ground truth.

## Labels

- Binary structural crack/surface-damage masks
- Binary pipeline masks
- Sonar peak locations embedded in the generated signal
- RGB, sonar and navigation timestamps
- Explicit calibration only for selected structural samples

## Intended use

- API and frontend demonstrations
- Unit/integration testing
- Measurement, coverage, synchronization and report validation
- Baseline algorithm evaluation

## Prohibited claims

This dataset must not be presented as field validation, production corrosion detection, certified NDT evidence, or proof of safety-critical performance.
